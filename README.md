# Meu Portfólio Pessoal - Anderson Amaral

Bem-vindo ao repositório do meu portfólio pessoal. Este projeto centraliza minhas habilidades, experiências e projetos, demonstrando minha jornada como Desenvolvedor Back-end.

**🚀 [Acesse a versão online aqui!](https://portfolio-andersondev.vercel.app/)**

## 📚 Seções do Portfólio

O site está organizado nas seguintes seções:

* **Página Inicial:** Uma breve apresentação com links para download do meu CV e redes sociais.
* **Sobre Mim:** Um pouco sobre quem eu sou, meus interesses e minha paixão por tecnologia.
* **Experiências:** Meu histórico profissional, incluindo as tecnologias que utilizei.
* **Educação:** Minha formação acadêmica na área de Análise e Desenvolvimento de Sistemas.
* **Projetos:** Uma vitrine com alguns dos projetos que desenvolvi.
* **Habilidades:** Um resumo visual das tecnologias e ferramentas que domino.
